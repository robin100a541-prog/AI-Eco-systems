# Konversationsarkiv (D-012)

Här sparas varje Claude-session som påverkar projektet, så att båda grundarna kan se exakt vad som sagts.

**Namngivning:** `ÅÅÅÅ-MM-DD-<grundare>-<ämne>.md`, t.ex. `2026-10-21-yorgo-fas0.md`.

**Innehåll:** grundarens meddelanden ordagrant och Claudes svar. Verktygsanrop (sökningar, filskrivningar) sammanfattas inte här — resultatet av dem finns i projektfilerna och i CHANGELOG.md.

**Viktigt:** arkivet är historik, inte regler. Det som gäller står i DECISIONS.md, ARCHITECTURE.md, REQUIREMENTS.md och PROJECT_STATUS.md.

**Rutin i slutet av varje session:** be Claude "spara den här sessionen i docs/conversations" och lägg filen i samma pull request som övriga ändringar.
