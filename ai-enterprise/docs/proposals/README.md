# Designförslag

Förslag inför nästa fas, skrivna av nattboten eller grundarna. **Bara text, ingen kod**, tills den
aktuella fasen är stängd. Ett förslag är inget beslut: grundarna avgör och skriver beslutet i
`DECISIONS.md`. En fil per förslag: `ÅÅÅÅ-MM-DD-<kort-namn>.md`, med mål, alternativ,
rekommendation och vilka krav eller paragrafer i konstitutionen förslaget bygger på.
